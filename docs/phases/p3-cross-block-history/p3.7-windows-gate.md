## 交互矩阵

### 1. Microsoft Pinyin / IME

- [ ] 使用 Microsoft Pinyin 连续输入 `输入法测试中文`，preedit、候选窗、选词和 commit 正常。
- [ ] 连续输入过程中没有重复字符、丢字符、光标跳位或 composition 残留。
- [ ] 中文标点与中英切换可以继续编辑。

### 2. Unicode / caret boundary

在普通 paragraph 中输入或粘贴：

```text
A中B 👍🏽 é abc אבג مرحبا
```

- [ ] Left / Right 连续移动不会把 emoji、combining sequence 或 UTF-8 文本破坏成非法状态。
- [ ] 选中并替换其中一段后文本保持正常，程序无 panic。
- [ ] BiDi 样例至少能正常显示、选中和编辑；P3 不要求完整专业级 BiDi caret policy，只要求现有 logical/canonical boundary 不被破坏。

### 3. Soft-wrap / visual-line navigation

把窗口缩窄，并在一个 paragraph 中粘贴足够长的中英文混合文本，使其明显产生多条 visual line。

- [ ] Home / End 作用于当前 visual line，而非直接跳到整个 block 首尾。
- [ ] Up / Down 跨多条 wrapped line 时保持合理的 desired x，没有明显横向漂移。
- [ ] 鼠标点击不同 wrapped line 时 caret 落在预期行附近。
- [ ] Shift + Arrow 跨 wrapped line 扩展 selection 时高亮连续且 caret 位置合理。

### 4. Cross-block selection / clipboard / history

跨 paragraph、quote 或 list item 做 selection：

- [ ] Copy 得到预期文本。
- [ ] Cut 后结构保持合法，未选 sibling 不被误删。
- [ ] Paste 后内容落在预期 selection seam。
- [ ] Undo 恢复 cut/paste 前内容与 selection。
- [ ] Redo 再次恢复编辑后状态。

### 5. List structural editing

在内置 bullet list 中操作：

- [ ] Enter 可以按当前语义拆分 list item。
- [ ] Backspace 在空项或项首执行既定 structural behavior，没有产生损坏结构。
- [ ] Tab / Shift+Tab 可以按现有规则 indent / outdent；没有上一 sibling 时不会错误嵌套。

### 6. Scroll / focus / keyboard-only path

- [ ] 在较长内容底部持续编辑和 Up / Down 导航时 caret 会保持可见。
- [ ] 手工滚动后，界面不会被每帧 scroll-to-caret 强行抢回。
- [ ] 不使用鼠标也能完成基本输入、方向键导航、selection、copy/paste、undo/redo 与保存。
- [ ] 窗口重新获得焦点后可以继续在当前 editor 输入，没有焦点落到错误 block。

### 7. Persistence

完成若干文本和结构编辑后：

- [ ] `Ctrl+S` 成功写入 `.\p3.7-windows-gate.txt`。
- [ ] 关闭窗口，再执行：

```powershell
cargo run -p xiaomu-editor-harness -- .\p3.7-windows-gate.txt
```

- [ ] 重新启动后刚才保存的 canonical 文本、marks 与已支持的 tree structure 均恢复，没有静默丢失。

说明：当前 standalone harness 的 store fixture 持久化 canonical document，不承诺持久化 selection。完整 `DocumentSelection` restore 与 native focus routing 已由 P3.6 `EditorInstance` / multi-editor host fixture 自动验证。
